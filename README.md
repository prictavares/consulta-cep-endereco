# Consulta CEP e Endereço

Este projeto é uma interface web simples que permite:

- Consultar **endereço a partir de um CEP**  
- Consultar **CEP a partir de um endereço (logradouro, cidade e estado)**  

As consultas utilizam a [API ViaCEP](https://viacep.com.br/).

## Como usar
1. Abra o arquivo `index.html` no navegador.  
2. Escolha a opção de consulta desejada.  
3. Informe o **CEP** ou o **endereço** e clique em **Buscar**.  
4. O resultado será exibido em uma tabela na própria página.  

## Tecnologias
- HTML  
- CSS  
- JavaScript  
- [API ViaCEP](https://viacep.com.br/)
